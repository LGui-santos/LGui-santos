### 🩸 Save Lives
**Status:** Concluído (2021)
**Reconhecimento:** 🥈 2º lugar na Faitec 2021
**Tecnologias:** Java 11, Maven, Spring Security, JDBC, PostgreSQL

**Descrição:** Projeto interdisciplinar desenvolvido para a Faitec (feira de tecnologia da FAI). A plataforma busca otimizar o trabalho dos hemocentros e atrair mais doadores, facilitando o agendamento de doações de sangue. O usuário se cadastra e agenda a doação escolhendo o hemocentro pela localização no mapa, com base em latitude e longitude.

**Principais funcionalidades**
- Cadastro de usuários e de hemocentros
- Autenticação e autorização com Spring Security
- Agendamento de doações por hemocentro, selecionado por localização
- Listagem de usuários, hemocentros e agendamentos

**Arquitetura:** API backend organizada em módulos separados (API, banco de dados, modelo e constantes), com acesso a dados via JDBC e PostgreSQL.

**Resultado:** 2º lugar na Faitec 2021.

[Ver repositório (backend)](https://github.com/LGui-santos/Save-Lives)
